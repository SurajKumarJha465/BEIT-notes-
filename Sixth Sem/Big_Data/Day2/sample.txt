[SECTION 4: SCENARIO ANALYSIS]
When a client requests a file read from HDFS, it talks to the NameNode.
The NameNode returns the locations of the blocks that make up the file.
The client then connects directly to the nearest DataNode to read the blocks.
This decentralized data transfer ensures that HDFS can scale out horizontally.
Hadoop MapReduce processes data by splitting jobs into Map tasks and Reduce tasks.
Map tasks run in parallel on local data stored across the cluster nodes.
Reduce tasks aggregate the intermediate values to produce the final output.
YARN stands for Yet Another Resource Negotiator and manages cluster resources.
YARN separates resource management from processing components.
This flexibility allows Hadoop to run non-MapReduce workloads like Spark and Flink.
